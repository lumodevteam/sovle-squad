# Solve Squad

Solve Squad is a math-based game, with a math difficulty level based on the Grade 6 Ontario Curriculum.

## Installation

Visit [solve squad](https://lumodevteam.github.io/sovle-squad/)

## How to play

WASD movement and shift to sprint  
E to interact

Your goal is to beat the game by finding the Lost Key for the cat lady in the village

## Features

Solve Squad features a big map with various terrains, as well as enemies and interactable npcs with dialogue

## Known Bugs

- When the player loses a battle, the player still has 0 health and can still enter battles
- Some of the questions are malfunctioning (eg. some shapes fail to render)
- Strand is currently set to only Data
- Can glitch player through solid objects using numbers
- Calculator can only do one operation at a time
